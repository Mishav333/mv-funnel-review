# MV Funnel Review

Scroll-through presentation format for MV Advisory's paid acquisition review product.

- `index.html`: concept chooser
- `concepts/a|b|c/`: three design directions, same content
- `shared/present.js`: presenter engine (scroll, arrow keys, section rail, font gate)
- `shared/data.js` / `data.json`: the single data source every number on screen binds to

Sample client "Halden Home Energy" is fictional. All figures are illustrative.
Never commit real client data to this repository.
